# 家庭の医学

年齢・性別・症状・病歴から、考えうる疾患を整理する家庭向けの参考アプリです。

## 注意

- 本アプリは**医療行為・確定診断ではありません**
- 緊急時（強い胸痛・呼吸困難・意識障害など）は **119** へ
- 表示結果は受診判断の補助情報です

## 使い方

```bash
npm install
npm run dev
```

ブラウザで表示された URL を開き、「症状を相談する」から入力を進めてください。

## 機能

1. **危険兆候のトリアージ**（胸痛・呼吸苦・麻痺・アナフィラキシー等）
2. 年齢・性別の入力
3. 症状の複数選択
4. スマホカメラ／写真による皮膚の見た目解析（端末内）
5. 病歴・体質の選択
6. 発症様式・熱・皮膚性状などの経過問診
7. 受診 disposition（119 / 救急 / 本日受診 / 経過観察）
8. 鑑別候補・要除外疾患・受診科の目安
9. 医師に渡せる受診メモのコピー

写真解析・候補提示は参考情報であり、診断の代替ではありません。
